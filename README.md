# 편입 길잡이

서울·경기·인천 4년제 대학 61곳의 일반편입·학사편입 정보를 학과·강점(영어 필기, 공인영어, 학점, 면접 등)으로 찾아보는 프로그램입니다.

- 웹에서 바로 쓰기: https://a72815799-art.github.io/transfer-guide-web/
- 파일로 받아 쓰기(인터넷 없이 동작): https://a72815799-art.github.io/transfer-guide-web/편입길잡이.html — 열린 화면에서 "파일로 내려받기"를 누르거나, 이 주소에서 다른 이름으로 저장하세요.

## 자료와 업데이트

- 각 대학 공식 모집요강을 정리한 **비공식** 자료입니다. 모든 항목에 요강 원문 링크와 쪽 번호가 있으니 지원 전에 반드시 원문을 확인하세요.
- "전년도 참고"는 2026학년도 요강 기준입니다. 2027학년도 요강이 나오는 대로 자료를 갱신합니다.
- 내려받은 파일은 인터넷에 연결되면 이 저장소의 `data.json`에 최신 자료가 있는지 한 번 확인합니다. 자료 파일을 받아 오기만 하며, 찜·검색어 등은 어디에도 보내지 않습니다. 인터넷이 없으면 파일에 들어 있는 자료로 그대로 동작합니다.
- 찜 목록은 사용하는 브라우저 안에만 저장됩니다.

## 파일

- `index.html`, `편입길잡이.html`: 프로그램(두 파일은 같음)
- `data.json`: 최신 자료(프로그램이 업데이트 확인에 사용)
